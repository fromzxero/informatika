Практическая часть

1. Постановка задачи
1.1 Описание предметной области

Предметная область — база статей в журнале, где ведётся  учёт статей по автору и теме статьи.
Система хранит информацию о статьях(автор, тема, статья). Пользователь может искать, смотреть статьи, а также добавлять в избранное, а администратор — добавлять, изменять и удалять данные о статье.

1.2	Цели и системы

•	Хранение всей информации  в одной системе
•	Быстрый поиск статей по критериям
•	Дать пользователям  возможность добавлять статью в избранное.
•	Добавление, изменение информации о статье

1.3 Пользователи системы (актеры) и их роли

1.	Администратор: Автор . Добавляет, изменяет,  удаляет статьи.
2.	Пользователь: Читатель. Просматривает и ищет статьи, имеет возможность читать статьи, добавлять статьи в избранное.

1.4 Основной функционал

•	Добавление новой статьи: ввод темы, названия, автора
•	Поиск статьи: поиск по автору, теме, названию
•	Просмотр информации о статье: прочтение статьи
•	Добавление статьи в Избранное: добавление статьи в личный раздел читателя
•	Изменение и удаление данных о статьях
